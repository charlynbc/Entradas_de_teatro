# 🎨🤖 PROMPT MAESTRO — ORDEN VISUAL Y UX BACO TEATRO (SIN CAMBIAR FUNCIONALIDAD)

```text
You are improving the visual organization and user experience of a mobile-first web application called "Baco Teatro".

IMPORTANT:
- Do NOT add new features.
- Do NOT change business logic.
- Do NOT remove existing functionality.
- Your task is ONLY to reorganize, clean and improve the visual layout and UX.

OBJECTIVE:
Make each user workspace look clean, elegant, modern ("cheto"), well-distributed and easy to understand,
while preserving all existing features and Baco Teatro branding.

GLOBAL RULES:
- Mobile-first design.
- Preserve Baco Teatro color palette.
- High legibility and contrast.
- Same colors, same identity, better order.
- No duplicated visual information.
- No clutter.
- Everything that exists must stay, but be better organized.

---

1) VISUAL ORGANIZATION PRINCIPLES

- One clear page title per screen (shown once).
- One main action per screen.
- Secondary actions grouped visually.
- Information grouped by meaning, not by origin.
- Use spacing, not repetition.
- No element should appear twice on the same screen.

---

2) LAYOUT STRUCTURE (ALL ROLES)

Each page must follow this structure:

- Header (reusable, consistent)
- Page title + short subtitle
- Main action card (highlighted)
- Secondary cards (grouped)
- Optional expandable sections
- Single footer (reusable)

Do NOT stack unrelated information vertically without separation.

---

3) ROLE-BASED ORDERING (KEEP CURRENT FEATURES)

DIRECTOR:
- Overview first
- Pending actions highlighted
- Groups → Works → Functions → Boletería → Reports
- Financial info clearly separated

ACTOR:
- Tickets and sales first
- Rehearsals and quotas second
- Group info last

SUPER:
- System overview first
- Users and groups next
- Reports and audits last

INVITADO:
- Discover → Details → Buy
- No distractions

---

4) VISUAL HIERARCHY

- Titles > Actions > Information
- Cards instead of raw lists
- Buttons clearly distinguished:
  - Primary (Baco main color)
  - Secondary (neutral)
- Icons only if they add clarity

Avoid:
- Walls of text
- Repeated labels
- Mixed priorities on the same screen

---

5) COLOR & BRANDING (BACO)

- Use Baco primary color for main actions.
- Secondary color for navigation and accents.
- Neutral background for readability.
- No white flashes or unstyled sections.
- Smooth scroll, continuous background.

---

6) CONSISTENCY RULES

- Same component = same style everywhere.
- Same action = same button color and position.
- Same information = shown once.

No exceptions.

---

7) MOBILE UX RULES

- Vertical flow
- Large touch targets
- Minimal typing
- Clear feedback after actions
- Collapsible sections preferred over long pages

---

EXPECTED OUTPUT:
- Reorganized layouts for each user role
- Cleaner visual hierarchy
- Better spacing and grouping
- Same features, better distribution
- Elegant, readable, mobile-first UI
- Strong Baco Teatro identity preserved
```
