Guía del Super Usuario

Visión General

Como Super Usuario (Administrador) tienes acceso completo al sistema BACO TEATRO para gestionar:

  • Todos los usuarios del sistema
  • Creación y asignación de roles
  • Gestión de grupos teatrales
  • Auditoría de todas las operaciones
  • Configuración general del sistema
  • Reportes y estadísticas
⚠️ Responsabilidad: Tienes acceso total al sistema. Con gran poder viene gran responsabilidad. Usa cuidadosamente estos privilegios.

Gestión de Usuarios

Administra todos los usuarios del sistema:

  • Crear usuario: Define cédula, contraseña inicial, nombre, email
  • Editar usuario: Actualiza datos personales o de contacto
  • Cambiar contraseña: Si usuario la olvida
  • Cambiar rol: Asigna rol (Director, Actor, Vendedor, etc.)
  • Bloquear usuario: Si hay mal comportamiento
  • Ver historial: Auditoría de acciones del usuario

Roles del Sistema

Los roles disponibles en BACO TEATRO son:

  • SUPER: Acceso total al sistema (solo tú)
  • DIRECTOR: Gestiona su grupo teatral y funciones
  • ACTOR: Participa en funciones del grupo
  • VENDEDOR: Vende entradas de funciones específicas
  • INVITADO: Puede ver funciones y contactar vendedores

Nota: Un usuario puede tener múltiples roles. Asigna según necesidad.

Gestión de Grupos Teatrales

Administra todos los grupos de teatro:

  • Crear grupo: Nombre, descripción, director responsable
  • Editar grupo: Actualiza datos del grupo
  • Asignar director: Selecciona quién dirige el grupo
  • Agregar integrantes: Asigna actores al grupo
  • Ver funciones: Todas las funciones de un grupo
  • Ver balance: Ganancias y gastos del grupo

Supervisión de Funciones

Monitorea todas las funciones del sistema:

  • Ve todas las funciones públicas y privadas
  • Revisa detalles de cada función
  • Monitored vendedores asignados
  • Verifica entradas vendidas
  • Edita o elimina funciones si es necesario
  • Maneja estados de funciones (publicada, cancelada, etc.)

Reportes y Estadísticas

Accede a información integral del sistema:

  • Total de usuarios por rol
  • Funciones activas y completadas
  • Entradas vendidas por grupo
  • Balance general de ingresos/gastos
  • Vendedores más activos
  • Exporta reportes en Excel/PDF

Auditoría y Seguridad

Mantén la integridad y seguridad del sistema:

  • Log de actividades: Ver todas las acciones en el sistema
  • Cambios de datos: Auditar quién cambió qué y cuándo
  • Accesos: Ver quién se conectó y cuándo
  • Bloqueos: Bloquea usuarios con actividad sospechosa
  • Backups: Realizar y verificar backups regulares
  • Reportes de seguridad: Detecta anomalías

Configuración General

Ajusta parámetros del sistema:

  • Configurar precios mínimos/máximos de entradas
  • Definir períodos de publicación de funciones
  • Ajustar comisión del sistema
  • Configurar notificaciones automáticas
  • Establecer límites de funciones activas
  • Configurar políticas de cancelación

Mantenimiento del Sistema

Tareas de mantenimiento regular:

  • Limpiar datos obsoletos (funciones pasadas)
  • Archivar datos de años anteriores
  • Validar integridad de la base de datos
  • Actualizar información de contacto
  • Respaldar sistema regularmente
  • Monitorear performance y velocidad

Responsabilidades Críticas

NUNCA:
  • Elimines datos de usuarios sin hacer backup
  • Cambies datos en la BD directamente sin usar la interfaz
  • Compartas tu contraseña con otros
  • Uses cuenta SUPER para tareas de usuario normal
  • Borres registros de auditoría
  • Hagas cambios masivos sin verificar primero

Mejores Prácticas

  • ✅ Realiza backups diarios del sistema
  • ✅ Revisa logs de auditoría semanalmente
  • ✅ Cambia tu contraseña cada 30 días
  • ✅ Usa contraseñas fuertes (15+ caracteres)
  • ✅ Documenta cambios importantes en un registro
  • ✅ Mantén sesión abierta solo durante trabajo necesario
  • ✅ Notifica cambios a directores que afecten sus grupos
  • ✅ Mantén comunicación con otros admins si hay varios

Soporte Técnico

Si necesitas ayuda técnica o hay problemas del sistema:

  • 📞 Contacta al equipo de soporte técnico
  • 💬 Reporta bugs en el sistema rápidamente
  • 📧 Documenta el problema detalladamente
  • 🔄 Mantén versión actualizada del sistema
  • 📋 Aprende de la documentación técnica
